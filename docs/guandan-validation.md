# Guandan 简化版：构建与四人联机验收

> 这是待执行的验收计划，不代表以下检查已通过。此 PR 未包含经典版规则。

## 1. CI 构建与自动化测试

在 GitHub Actions 运行 PR 的 CI 工作流，或本地使用 Node.js 24：

```bash
npm ci
npm -w guandan run typecheck
npm -w guandan run test
npm run test
npm -w client run build
```

全部通过才满足构建门禁。如 Fork 仓库尚未启用 Actions，请先在 GitHub → Actions 启用工作流，再执行上述命令。

## 2. 四人真实联机

```bash
npm run dev
```

- 开启 4 个独立登录用户/浏览器配置文件（不能复用同一账号）。
- 同一局域网电脑访问 `http://localhost:5173`；手机使用电脑局域网 IP 的 5173 端口。开发服务器必须绑定 LAN 地址，Socket.IO Vite 代理须可连接服务器 3000 端口。
- 在大厅选择 `guandan-simple`，创建房间；另外 3 个玩家通过房间码/邀请链接加入。
- 所有人准备后开始，逐一确认每人 27 张手牌、其他玩家仅显示张数。
- 验证四人出牌、压制、过牌、清空本轮、接风、同队双上及最终结算。
- 在对局中把一个人断网，45 秒内重连；恢复牌局且隐藏信息不泄漏。
- 断网超过 45 秒：其对手队伍获胜，两个客户端必须显示相同团队结果。
- 手机 Safari、Android Chrome、桌面 Chrome/Safari 分别进行触控与布局测试。
